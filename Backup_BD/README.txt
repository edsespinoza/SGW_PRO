SGW PRO v11.0.0 — ABERAMA BRASIL
========================================================

COMO ABRIR O SISTEMA:
  1. Abra o arquivo "SGW Pro.html" no Chrome ou Edge
  2. Ou execute: python3 -m http.server 8080
     e acesse http://localhost:8080/SGW%20Pro.html

ESTRUTURA DESTA PASTA:
  SGW Pro.html  -> Sistema completo (abrir no Chrome/Edge)
  backups/      -> Arquivos .txt de backup das licencas
  README.txt    -> Este arquivo

COMO RESTAURAR UM BACKUP:
  1. Abra SGW Pro.html
  2. Va em: Configuracoes > Importar Backup .txt
  3. Selecione o arquivo backup_*.txt desejado

FREQUENCIA RECOMENDADA:
  Ative o backup automatico em Configuracoes.
  Mantenha copias em nuvem ou pendrive externo.
