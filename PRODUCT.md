# SGW Pro

> Sistema de controle de licenças SGW Stellantis para técnicos automotivos.

## Register

product

## Users

- Técnicos automotivos especializados em scanners SGW Stellantis (portfólio de R$8k a R$50k)
- Distribuidores e revendedores de licenças SGW
- Profissionais que gerenciam múltiplas ativações, assinaturas ADAS e dados de equipamentos

## Product Purpose

Centralizar o controle de licenças SGW Stellantis com segurança corporativa: emissão, renovação, relatórios financeiros, certificados PDF, extração de dados de ativação e backup local.

## Brand Personality

- **Técnico e profissional** — linguagem precisa, séria e confiável
- Segurança em primeiro lugar (criptografia AES-256-GCM, JWT, HTTPS)
- Visual escuro e sóbrio (dark mode), inspirado em ferramentas profissionais
- Design orientado a dados: dashboards, tabelas, KPIs

## Anti-references

- Não é SaaS genérico — não usar tons pastel, cards arredondados exagerados, ilustrações fofas
- Não é site institucional — evitar hero sections genéricas com gradient text
- Não é ferramenta casual — evitar cores vibrantes demais, animações bouncy

## Strategic Design Principles

1. Dados primeiro — toda tela deve comunicar informação útil sem ruído visual
2. Ações rápidas — shortcuts (Ctrl+S, Ctrl+N, Ctrl+P), busca global (Ctrl+K)
3. Offline first — IndexedDB como fallback, API como primary
4. Escuro por contexto — técnicos usam em oficinas, ambientes com pouca luz
